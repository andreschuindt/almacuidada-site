## Deploy
Este diretório já é publicado automaticamente pelo projeto Vercel ligado ao repositório `andreschuindt/almacuidada-site`.

Para usar um projeto Vercel separado, configure:
- Project name: `conselhosdeummaupai`
- Root Directory: `conselhosdeummaupai`
- Framework Preset: Other / Static
- Production branch: `main`

A URL desejada será `https://conselhosdeummaupai.vercel.app` se o slug estiver disponível.
